# Tool Function

Use Clang to extract function interfaces from the source code directory and save them to a JSON file.

## Dependencies

clang

## Instructions

1. Enter two parameters. The first parameter indicates the name of the source package to be scanned, and the second parameter indicates the path of the source package.
2. For example, run the **python3 clang_extract_api.py glibc /root/test/glibc-2.17** command.
