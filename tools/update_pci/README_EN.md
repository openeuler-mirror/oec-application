# File Description

## Description

Query the board in the compatibility list. If it is not in the **pci.ids** file, insert its information in a certain format.

## Usage

```python
python pci.py pci.ids path: path of the compatibility list
```

Example:

```sh
Compatibility List of Two Types of Platform Boards on python pci.py  D:\pci\pci.ids D:\pci\openEuler20.03-LTS-SP1.xlsx
```

Remarks: The path can be an absolute or relative path.

Obtain the compatibility list from https://gitcode.com/openeuler/website-v2/tree/master/data/compatibility.
